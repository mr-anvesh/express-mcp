# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's **Report a vulnerability** option in the repository's Security
tab to send a private report. If that option is unavailable, contact the
maintainer privately through GitHub and include a way to follow up. Please
include the affected version, the impact, and steps to reproduce or a proof of
concept when safe to do so. Avoid sharing real credentials, personal data, or
data belonging to other users.

You can expect an acknowledgement and coordinated discussion of the report.
Response and fix timelines depend on severity and maintainer availability;
please allow time for investigation before making details public.

## Supported versions

Security fixes are generally made to the latest released version. Users should
upgrade to the latest version when a fix is available.

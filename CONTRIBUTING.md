# Contributing

Thanks for considering a contribution to `express-mcp-server`! Bug reports,
documentation improvements, and focused code changes are welcome.

## Before you start

- Check the existing issues and pull requests to avoid duplicating work.
- For a substantial change, open an issue first to discuss the approach.
- Keep changes focused and preserve compatibility unless a breaking change has
  been discussed.

## Development

1. Fork the repository and clone your fork.
2. Install dependencies with `npm install`.
3. Create a branch for your change.
4. Make the change and add or update tests and documentation where appropriate.
5. Run `npm run build` before submitting.

The project is written in TypeScript. Follow the surrounding code style and
avoid adding runtime dependencies without first discussing the need.

## Pull requests

- Explain the problem and the approach in the pull request description.
- Include steps to reproduce or verify behavior for bug fixes and feature
  changes.
- Keep each pull request focused; update the README or other docs when public
  behavior or usage changes.
- Be responsive to review feedback and keep the branch up to date when needed.

By submitting a contribution, you agree that it may be distributed under the
project's [ISC license](LICENSE).
